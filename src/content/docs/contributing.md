---
title: Как править вики
description: Как предложить правку или добавить страницу в вики MineHouse.
---

Вики хранится на GitHub в репозитории [P5ina/minehouse-wiki](https://github.com/P5ina/minehouse-wiki). Каждая страница это обычный Markdown-файл в папке `src/content/docs`. После того как правку примут, сайт обновится сам примерно через минуту.

## Поправить страницу

1. Внизу любой страницы нажми **«Редактировать страницу»**. Нужен аккаунт на GitHub.
2. Поправь текст прямо в браузере. Вкладка **Preview** показывает, как это будет выглядеть.
3. Нажми **Commit changes…**, коротко опиши, что поменял, и выбери **Create a new branch and start a pull request** (если у тебя нет прав на запись, GitHub сам сделает копию и предложит pull request).
4. Нажми **Create pull request**. Под ним через минуту появится ссылка на предпросмотр сайта с твоей правкой.

Правку проверит и примет редактор вики или админ. Если у тебя роль «Редактор вики» в Discord, напиши админам свой ник на GitHub, и тебя добавят в репозиторий: тогда ты сможешь принимать правки сам.

## Добавить страницу

Создай файл `src/content/docs/<адрес>.md`, например `metro.md` станет страницей `wiki.minehouse.pro/metro/`. В начале файла нужен заголовок:

```md
---
title: Метро
description: Одна строка о том, что на странице.
---

Текст страницы.
```

Чтобы страница появилась в боковом меню, добавь её адрес в `sidebar` в файле `astro.config.mjs` (или попроси это сделать того, кто будет принимать правку).

## Как писать

- Ссылка на другую страницу вики: `[Правила](/rules/)`.
- Ссылка на сайт: `[личный кабинет](https://minehouse.pro/account)`.
- Картинки клади в `src/assets/` и вставляй так: `![Подпись](../../assets/картинка.png)`.
- Заметки и предупреждения:

  ```md
  :::tip
  Полезный совет.
  :::

  :::danger[Внимание]
  Важное предупреждение.
  :::
  ```

Полный список возможностей разметки есть в [документации Starlight](https://starlight.astro.build/ru/guides/authoring-content/).

## Черновики

Страница с `draft: true` в шапке видна только в локальном предпросмотре (`pnpm dev`), на сайт она не попадает. Так заранее написаны механики, которые игрокам пока не открыли. Когда механику откроют, удали строку `draft: true` и отправь PR.
