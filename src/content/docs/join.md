MineHouse это Vanilla+ сервер на **Minecraft Java 26.3** (Fabric). Лицензия не нужна, подойдёт любой лаунчер.

## Что нужно

- Minecraft Java Edition **26.3**.
- Аккаунт Discord и участие в [нашем Discord-сервере](https://discord.gg/gCYGxDzaCb). Без него войти не получится: так мы защищаем ники.

## Шаг 1. Вступи в Discord

Перейди по [приглашению](https://discord.gg/gCYGxDzaCb). Там же новости, помощь новичкам и бот для входа.

## Шаг 2. Добавь сервер

В игре: **Сетевая игра → Добавить сервер**, адрес:

```
play.minehouse.pro
```

## Шаг 3. Подтверди вход кодом

Перед входом в мир игра покажет окно с одноразовым кодом. Подтверди его одним из способов:

1. На сайте: [войди через Discord](https://minehouse.pro/login) и введи код на странице [подтверждения](https://minehouse.pro/approve).
2. В Discord: отправь боту команду `/вход 482913` (со своим кодом).

Окно в игре закроется само, и ты окажешься в мире. Устройство запоминается на 7 дней, потом код спросят снова.

:::danger[Никогда не подтверждай чужой код]
Подтверждение пускает того, кто сейчас в игре, под твоим ником. Если запрос не твой, нажми «Это не я».
:::

## Если ник уже занят

Ник закрепляется за Discord при первом подтверждении. Если кто-то занял твой ник, напиши админам в Discord. Если у тебя лицензия Minecraft, её можно подтвердить в [личном кабинете](https://minehouse.pro/account), и вход будет проверяться через Mojang.

## Несколько ников

В [личном кабинете](https://minehouse.pro/account) можно привязать несколько ников к одному Discord и выбрать основной: он показывается в Discord.
